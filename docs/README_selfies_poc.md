# PoC: SELFIES Tokenizer + Tiny Regressor

This document describes the proof-of-concept CLI and artifacts produced by the SELFIES tokenizer PoC.

## Purpose

The PoC demonstrates a minimal workflow that:
- builds a bracket-token SELFIES vocabulary,
- trains a tiny PyTorch regressor that consumes SELFIES token ids, and
- saves a checkpoint containing the model state and the tokenizer vocabulary.

This is pedagogical — use a larger dataset and a transformer encoder/tokenizer for real tasks.

## Script

- `src/selfies_tokenizer_poc.py`
  - Reads CSV train/val/test splits
  - Builds a bracket-token vocabulary (tokens like `[C]`, `[=O]`)
  - Trains a tiny embedding + pooling regressor
  - Saves a checkpoint (PyTorch `.pth`) with vocab and args

## Expected Inputs

CSV files (produced by `src/build_hf_dataset.py`) with at least these columns:
- `text`: SELFIES string (e.g. `[C][=O][Branch1]...`)
- target column name such as `DV_C` or `DV_n`

Typical paths used in examples:
- `data/hf_dataset_small_train.csv`
- `data/hf_dataset_small_val.csv`
- `data/hf_dataset_small_test.csv`

## Outputs

- `models/poc_selfies/poc_selfies.pth` — PyTorch checkpoint (dictionary) containing:
  - `model_state_dict`: weights of the `TinySelfiesRegressor` model
  - `stoi`: token -> id mapping
  - `itos`: id -> token list
  - `args`: CLI arguments used for the run

The checkpoint can be loaded with `torch.load(...)`. Recreate the model with the same architecture and call `model.load_state_dict(checkpoint['model_state_dict'])`.

## Vocab & Tokenizer

- Tokenization method: bracket-token splitting (regex or `selfies.split_selfies` if the `selfies` package is available).
- Special tokens: `<PAD>`, `<UNK>`
- `stoi` and `itos` are saved in the checkpoint for later inference.

## Example Run

```bash
python src/selfies_tokenizer_poc.py \
  --train data/hf_dataset_small_train.csv \
  --val data/hf_dataset_small_val.csv \
  --test data/hf_dataset_small_test.csv \
  --target DV_C \
  --out models/poc_selfies/poc_selfies.pth \
  --epochs 5 \
  --batch_size 2
```

## Requirements

- Python 3.8+
- `pandas`, `numpy`, `torch`, `scikit-learn`
- `selfies` is optional; the script falls back to regex splitting if not installed.

Install (example):

```bash
pip install pandas numpy scikit-learn
# Install torch via conda or pip depending on your platform
# pip install torch
```

For RDKit use or if you prefer a conda environment, use `environment_selfies.yml` provided in the repo.
